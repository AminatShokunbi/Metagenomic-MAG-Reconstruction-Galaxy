# Software Citations

This file records the software and methodological references for the completed Version 1.0 demonstration and the Version 2.0 MAG reconstruction. The Version 2.0 analysis implemented MetaBAT2, MaxBin2, CONCOCT, DAS Tool and CheckM2 and recovered six candidate genome bins. GTDB-Tk was not required for the reconstruction objective and was not represented as a completed analysis.

## Galaxy

The Galaxy Community. (2026). Galaxy for accessible, reproducible, and collaborative data analyses: 2026 update. *Nucleic Acids Research*, **54**(W1), W105–W116. https://doi.org/10.1093/nar/gkag469

## SRA Toolkit / FasterQ Dump

FasterQ Dump is distributed as part of the NCBI SRA Toolkit. Version 1.0 used FasterQ Dump to retrieve sequencing reads from the selected SRA accessions. The software and its documentation are maintained by the National Center for Biotechnology Information (NCBI): https://github.com/ncbi/sra-tools

## FastQC

## MultiQC

## Cutadapt
